========================================================================
             คู่มือการนำโปรเจกต์ Golden River Web ไปทำต่อบนเครื่องใหม่
========================================================================

สิ่งที่ต้องมีบนเครื่องใหม่:
1. Node.js (แนะนำเวอร์ชัน LTS เช่น v18, v20 หรือ v22)
   - ดาวน์โหลดและติดตั้งได้ฟรีที่: https://nodejs.org
2. Git (เพื่อใช้คำสั่ง push อัพเดตขึ้น Vercel / GitHub)
   - ดาวน์โหลดและติดตั้งได้ฟรีที่: https://git-scm.com

------------------------------------------------------------------------
ขั้นตอนการเริ่มใช้งานบนเครื่องใหม่:
------------------------------------------------------------------------
1. ติดตั้งระบบครั้งแรก (ทำแค่ครั้งเดียว):
   - ดับเบิ้ลคลิกไฟล์ "1_ติดตั้งครั้งแรก (Install).bat"
   - รอระบบรันคำสั่ง npm install จนขึ้นข้อความ [สำเร็จ]

2. เริ่มรันเว็บไซต์:
   - ดับเบิ้ลคลิกไฟล์ "2_เริ่มรันระบบ (Start Dev).bat"
   - เปิดบราวเซอร์ (เช่น Chrome) เข้าใช้งาน:
     * หน้าเว็บหลัก: http://localhost:3000
     * หน้าหลังบ้าน (Admin Portal): http://localhost:3000/admin
     * รหัสผ่านเข้าหลังบ้าน: 8888

3. เมื่อมีการแก้ไขเนื้อหา หรืออัพโหลดรูปภาพ แล้วต้องการอัพเดตขึ้น Vercel (เว็บจริง):
   - ดับเบิ้ลคลิกไฟล์ "3_อัพเดตขึ้น Vercel (Push to GitHub).bat"
   - ระบบจะส่งไฟล์ขึ้น GitHub (origin main) และ Vercel จะ build อัพเดตหน้าเว็บจริงให้ทันที
